# Audition Manager App
## これは何？
Audition Manager Appは、千葉大学アカペラサークルT.o.N.E.で実施される審査の運営を補助するために作られたツール群です。
v1.0.0時点において、以下のAppが使えます。
- Timetable Maker App(演奏順をランダムにしたタイムテーブル作成)
- Score Processor App(偏差値法による点数処理)
- Feedback Maker App(未完成)(フィードバックシートの作成支援)
## 使い方
Windows版とMacOS版が用意されています。実行ファイルになっているため、基本的にはダブルクリックで起動が可能です。
ただし、MacOS版は、仕様上、セキュリティの例外にする必要があります。ウイルス等は含まれていないのでご安心ください。

# Timetable Maker App
## これは何？
Timetable Maker Appは対面審査におけるタイムテーブルの作成をするものです。インポートされたバンド情報と日程情報からランダムに並び替えることで、各バンドの出演不可能時間に対応して誰も連続出演にならないようにします。
## 使い方
1. 「設定ファイル出力」を押して、「バンドCSV.csv」、「スケジュールCSV.csv」を出力する。
1. 「バンドCSV.csv」<sup>※1</sup>、「スケジュールCSV.csv」に必要な事項を入力する。入力の仕方は出力されたファイルを参照。ファイル名は任意に変更して良い(なんなら変更を推奨)。
1. BandInfoAppで、バンド情報を入力したcsvを読み込ませる。「unavailable_time」列に、各バンドの出演不可能時間を入力する。alternative」「列で、動画代替等により連続を考慮する必要がないバンドを指定する。
1. ScheduleInfoAppで、審査の日程情報を入力したcsvを読み込ませる。日程が始まる時刻を上のボックスに入力し、時刻を確認する。
1. TimetableMainAppで、確認のチェックを2ついれる。ランダマイズを行う最大回数と、ステージ外待機分数<sup>※2</sup>を入力し、実行する。完了したら順番の結果と試行回数ログの出力先が表示される。

<sup>※1</sup>ScoreProcessorAppと同じファイルで問題ありません。
<sup>※2</sup>ステージ外待機分数が15分、あるバンドの出演不可能時間が10:00-11:00となっているとき、並べ替えの際、そのバンドが9:45-11:00に該当しないようにします。これは、日程上割り当てられたステージ上にいる時間の外で待機や声出しをする時間について設定を適用するための機能です。
# Score Processor App
## これは何？
Score Processor Appは偏差値法に基づく点数処理を行うものです。インポートされたバンド情報、項目情報、採点データから偏差値法を用いて処理を行います。
## 使い方
1. 「設定ファイル出力」を押して、「バンドCSV.csv」、「採点項目CSV.csv」、「採点データCSV.csv」を出力する。
1. 「バンドCSV.csv」<sup>※3</sup>、「採点項目CSV.csv」、「採点データCSV.csv」<sup>※4</sup>に必要な事項を入力する。入力の仕方は出力されたファイルを参照。ファイル名は任意に変更して良い(なんなら変更を推奨)。
1. ConfigAppで、バンド情報を入力したcsv、採点項目を入力したcsvを読み込ませる。
1. DataTreatmentAppで、採点データのcsvを読み込ませる。読み込みの際のポップアップでは、審査員名に該当する列名にチェックを入れる。
1. ProcessingMainAppで、確認のチェックを3ついれる。審査員に求める審査したバンド数の最小値を入力する。あるバンドにつけられた点数の最大最小を除外して平均を出す(トリム平均)かどうかを選択する。実行したら、結果が偏差値の高い順と各種ログの出力先が表示される。

<sup>※3</sup>ScoreProcessorAppと同じファイルで問題ありません。
<sup>※4</sup>所定のGASを用いて出力したGoogle Formの回答データを想定しています。
